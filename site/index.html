Claude Code / marketplace

/plugin marketplace add fabiandistler/agents
/plugin install architecture@fabiandistler-agents

Start with architecture. Install other category plugins when you need them. For Claude Desktop, claude.ai, and Cowork, use the plugin guide.

Codex CLI / local skills

git clone https://github.com/fabiandistler/agents.git ~/src/agents
cd ~/src/agents
./install.sh --target=codex

Requires Bash, Git, and Python 3. The skills stay linked to your local clone. See the guide for updates and optional guard hooks.
